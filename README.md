# أخبار ومظهر زمرد

لوحة الإدارة: https://tarekdev33-ops.github.io/zoumourd-mobile-updates/

هذا المستودع عام ويحتوي اللوحة والأخبار والصور المنشورة فقط. لا ترفع إليه بيانات مستخدمين أو مفاتيح تفعيل أو مفاتيح خدمة أو نسخة التطبيق الخاصة.

## النشر من المتصفح

أنشئ Fine-grained personal access token في GitHub، وحدد هذا المستودع فقط وصلاحية Contents: Read and write. أدخله في اللوحة؛ يتم تذكره في المتصفح بعد التحقق، ويمسحه تسجيل الخروج. لا تضعه في config.json أو الصور أو روابط الأخبار.

جهز الخبر أو المظهر واحفظه، ثم اضغط **نشر التغييرات**. الأخبار غير المنشورة محلية حتى إغلاق الصفحة. التعارض بين جلستين يُرفض؛ أعد الاتصال لتحميل النسخة الأخيرة. المواعيد بتوقيت دمشق.

التطبيق المتصل يقرأ config.json عند البداية والعودة وكل دقيقتين أثناء التشغيل، ويحفظ الأخبار والصور والمظهر محليًا. يبدأ وينتهي العرض حسب المدة على الجهاز حتى دون إنترنت.

الإشعارات منفصلة: من Firebase Messaging أرسل Notification إلى topic باسم zoumourd-news-v1 بعد تثبيت نسخة التطبيق المربوطة وموافقة المستخدم على الإشعارات. نشر الأخبار هنا لا يرسل FCM تلقائيًا ولا يحتاج Cloud Functions أو خطة Blaze.

## تحديث اللوحة

يُعاد بناؤها من المصدر الخاص. يجب حفظ config.json وpublic-assets والصور القديمة عند تحديث ملفات اللوحة. أداة النشر في المصدر الخاص تفعل ذلك تلقائيًا.
